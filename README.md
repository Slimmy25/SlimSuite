# Slim Suite (AZSMinorMods)

An addon for Azeroth Survivors by Slimjim: a movable default UI with a set of small extras.

## Install

1. Download the latest `AZSMinorMods-<version>.zip` from the Releases page.
2. Extract the `AZSMinorMods` folder into your game's `Interface/AddOns` folder.
3. Restart the game.

## Source

The addon files are in the `AZSMinorMods` folder. Edit them, then zip that folder to test your own build.

## Releases

Each release attaches `AZSMinorMods-<version>.zip`, which contains the `AZSMinorMods` folder.
